## Setup

- `npm install` — install dependencies
- `npm run dev` — start the local dev server (http://localhost:4321)
- `npm run build` — build the production site into `dist/`
- `npm run preview` — serve the built `dist/` locally to test the production build
- `npm run gen:worldmap` — regenerate `src/data/world-dots.json` for the About map

There is no test runner yet. When one is added (e.g. Vitest or Playwright),
record the command to run a single test here. `npx astro check` (the type-checker)
needs `@astrojs/check` + `typescript` installed first — not currently added.

**Machine switches:** never copy `node_modules` between computers/OSes — the bin
files lose their exec bit and symlinks break, which shows up as a
`Permission denied` on `astro` when you run `npm run build`. `node_modules` is
gitignored, so after switching machines just do a clean
`rm -rf node_modules && npm install` if the build fails oddly.

## Architecture

Static Astro site. Pages are built to plain HTML at build time; the only client
JS is a small vanilla script in `BaseLayout` (keyboard nav + theme toggle).

- `src/pages/` — file-based routing; each file is a route. Home (`index.astro`)
  is the terminal "app window"; `about`, `career`, `colophon`, and `blog/` are
  plain inner pages. `blog/[...slug].astro` renders one post per Markdown file.
- `src/layouts/` — `BaseLayout` (shared `<head>`, chrome, keyboard/theme scripts;
  imports `global.css`) and `BlogLayout` (wraps a single post).
- `src/components/` — reusable UI: `Nav`, `Footer`, `AppWindow`, `Prompt`,
  `Cursor`, `PostCard`, `WorldMap`.
- `src/content/blog/` + `src/content.config.ts` — the `blog` content collection.
  Add a post = drop a `.md` file (frontmatter: title, date, description, tags?).
- `src/styles/global.css` — Tailwind entry, design tokens via `@theme` (colors,
  fonts; light theme under `html[data-theme="light"]`), and blog `.post-body`
  prose styles.
- `src/data/world-dots.json` — generated by `scripts/gen-world-dots.mjs`
  (`npm run gen:worldmap`), consumed by `WorldMap`.
- `astro.config.mjs` — Tailwind Vite plugin + `site: 'https://stanferd.dev'`
  (used for canonical / Open Graph URLs).
- `public/` — static assets served as-is (favicons).

### Design system
Terminal / CLI aesthetic, dark by default. Tokens: bg `#0d1117` (window),
`#010409` (desktop), text `#c9d1d9`, accent green `#1cb03a`, muted `#8b949e`.
Fonts: Space Grotesk (display), Newsreader (body), Space Mono (terminal/code),
loaded from Google Fonts. `[d]` toggles light/dark (persisted); `[a]/[b]/[c]/
[x]/[h]` are keyboard nav.
